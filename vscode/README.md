# Edgar++ za VS Code

Povezuje lokalnu C datoteku u stolnom VS Codeu s uređivačem zadatka za vježbu na Edgaru. Za sinkronizaciju instaliraj [Edgar++ za Firefox](https://addons.mozilla.org/firefox/addon/edgar-plus-plus/) i u Edgarovoj alatnoj traci klikni **VS Code · Spoji**.

Sinkronizacija radi između preglednika i VS Codea putem lokalne veze na računalu. Postojeća lokalna datoteka pri spajanju služi kao početna verzija. Provjeru u Edgaru pokrećeš zasebno naredbom **Edgar: Pokreni provjeru**.

Naredba **Edgar: Lokalno provjeri primjere** prevodi C kod pomoću GCC-a i uspoređuje izlaz s primjerima koje uneseš. Za tu naredbu potreban je GCC na putanji `PATH`.
